White L1: How Python runs code & print(). Python is a very literal three-wheeler driver: it goes exactly where you say. 🛺

  1. A .py file is just textIt holds instructions, one per line.
  2. Top to bottomThe interpreter runs line 1, then line 2, so order matters.
  3. print() shows outputIt is how you see what your program is thinking.
  4. Text needs quotes"Colombo" is text; 750000 is a number.
  5. Commas add spacesprint("Hi", 5) shows Hi 5.

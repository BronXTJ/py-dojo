# Py Dojo: White Belt (React + TypeScript + Vite)

Learn Python step by step with a living Sri Lanka map. Runs fully offline.

**Open it:** open `dist/index.html` directly (file://) in Chrome, Firefox or Safari, and keep `dist/pyodide/` next to it (that folder is the offline Python engine). It also works from any static host or sub-path, such as GitHub Pages at `/py-dojo/`, because routing uses `#/…` hashes and every asset path is relative.

```
npm install
npm run dev        # dev server
npm run build      # typecheck + vite (single-file index.html) + copy pyodide -> dist/
npm test           # vitest unit tests
npm run lint       # eslint (strict TypeScript)
npm run typecheck
npm run verify     # run every answer/solution/quiz/bug/error/glossary example in real Pyodide
npm run qa -- chromium|firefox|webkit   # acceptance suite (env: PYDOJO_URL, PYDOJO_SHOTS, PYDOJO_SIZES, PYDOJO_ONLY, CHROME_PATH, CHROME_NO_SANDBOX)
npm run gen        # regenerate src/content/* from tools/content-src and /tmp/olddata.json
```

## What's inside
- **Dojo (home):** a "where you are / next step" card, Review due count, Word of the Day, and the belt map from White to Master, shown in the real belt colours. White has its 15 lessons; the other belts are locked and marked "coming soon", with their topics and boss fights listed. Export and Import of progress are here too.
- **15 White Belt lessons**, each in 7 stages: Hook (Think-first + Look-back links) → Learn → Watch (predict first, time-travel scrubber) → Try (Living Lanka task, Understand/Plan/Build/Reflect, hints, fresh variants) → Fix the bug (bug creature) → Quiz → Reward (Founder's Challenge + deeper dive, Next lesson, Redo).
- **Review:** a spaced-repetition (Leitner) queue fed by quiz answers, with fresh numbers each time.
- **Practice:** 5 freshly generated exercises per lesson (coding + quiz + spot-the-error).
- **Error Encyclopedia:** 43 errors, with search, filter, the exception family tree, and a "run it for real" button.
- **Glossary:** 1,247 terms with search, belt and category filters, an A–Z jump, and Word of the Day. The list is windowed. Snippets that cannot run in the vendored Pyodide are marked display-only.
- Autosave (localStorage `pydojo-v2`), day/night theme, 44px touch targets, keyboard access, and reduced-motion support.

## Structure
- `src/content/`: typed content. `lessons.ts` is hand-written (the per-lesson choices). `glossary.ts` is written by `scripts/glossary_build.py`. The other modules are generated by `scripts/gen-content.py` from `tools/content-src` plus a `/tmp/olddata.json` dump of the original belt and error tables.
- `src/screens/`: the screens: Home, LessonScreen, Errors, Glossary, Review, Practice.
- `src/components/stages/`: the 7 lesson stages.
- `src/components/scene/`: the Living Lanka scene.
- `src/components/panel/`: the editor, runner and scrubber.
- `src/store.ts`: progress, autosave, spaced repetition, export/import.
- `src/session.tsx`: run/playback state.
- `src/router.ts`: hash routes.
- `src/py/`: Pyodide worker and engine. The engine is served from memory, so WebKit's file:// rules can't block it.
- `tests/qa.cjs`: layout, contrast and scene audits on every screen, plus a 15-lesson journey, base-path, reduced-motion, keyboard and touch-target checks.
- `tests/verify.cjs`: runs all content in Pyodide.
